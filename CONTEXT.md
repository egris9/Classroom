# Classroom glossary

- **User**: an account. Has no global role.
- **Course**: a class. Has one teacher and any number of students.
- **Membership**: a user's relationship to one course. Gives a role: Teacher, Student or None.
- **Teacher**: the user who created a course. It is a role within one course, not an account type.
- **Student**: a user who joined a course with its access code.
- **Access code**: the 8-character code a user enters to join a course. It is not a course id.
- **CourseFile**: a PDF uploaded to a course by its teacher.
- **Summary**: AI-generated text summarising a CourseFile. Teacher-triggered ones are published to the course. Student-triggered ones are private.
- **Exercise set**: AI-generated questions for a CourseFile, with the same published/private rule as a Summary.
- **TextGeneration**: the seam through which the app asks a model for summaries and exercises.
